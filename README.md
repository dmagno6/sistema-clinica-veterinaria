# **_Projeto_**

  O projeto consiste no desenvolvimento de um sistema para gerenciar uma clínica veterinária, abrangendo o atendimento e tratamento de animais domésticos e a venda de produtos veterinários.

# **_Objetivo_**

  O sistema tem como objetivo organizar e facilitar o gerenciamento das informações da clínica, permitindo o cadastro de clientes, animais e veterinários, além do controle de consultas, tratamentos, produtos e vendas. Dessa forma, as informações ficam centralizadas e relacionadas, facilitando o acompanhamento dos atendimentos e das atividades da clínica.

# **_Público-alvo_**

  Clínicas veterinárias e funcionários responsáveis pelos atendimentos e pelo gerenciamento dos serviços e produtos.
